# User docs

Docs that help you adopt and use the Agent Factory set as a whole. Each child repository keeps its own
`user-docs/` for its tool; the table at the end links to all of them.

| Document | For |
|---|---|
| [adoption-guide.md](adoption-guide.md) | What AFS gives a team, the rollout path, and the first agent with the console or the CLI |
| [getting-started.md](getting-started.md) | Clone the set, install toolchains, find the right repository for a task |

## Guides in each repository

| Repository | Guides |
|---|---|
| -db | [index](https://github.com/stainedhead/enterprise-agent-factory-service-db/blob/main/user-docs/README.md): getting started, configuration, operations (backups, restore, releases) |
| -restapi | [index](https://github.com/stainedhead/enterprise-agent-factory-service-restapi/blob/main/user-docs/README.md): deployment, configuration, authentication and limits, reconciler, observability, reports, billing, work orders, export and import |
| -cli | [index](https://github.com/stainedhead/enterprise-agent-factory-service-cli/blob/main/user-docs/README.md): install, configuration, SSO, output, pagination, errors, examples per area, command reference |
| -website | [index](https://github.com/stainedhead/enterprise-agent-factory-service-website/blob/main/user-docs/README.md): console, console examples, SDK, SDK examples, configuration |
