Create team endpoint

Adds an OpenAI-compatible model service only this team can use. Every call is metered by the team gateway.

Endpoint and route

Lowercase letters, digits and hyphens. Agents see it in URLs and in AFS_LLM_CODER_VLLM_BASE_URL. Cannot be changed.

Equivalent CLI

afs model-endpoints create-model-endpoint \
  --team-id team_01JD3Z… \
  --slug coder-vllm \
  --location in_namespace \
  --base-url http://vllm-coder:8000/v1 \
  --protocol openai_chat openai_embeddings \
  --auth-kind none \
  --pricing-mode capacity \
  --owner marcus.chen \
  --purpose "Cheap code completion"
afs budgets put-token-quota \
  --team-id team_01JD3Z… \
  --route coder-vllm --period monthly \
  --max-tokens 50000000

What agents get

Agents with this route receive AFS_LLM_CODER_VLLM_BASE_URL and an entry in /etc/afs/llm-routes.json on their next restart. They never call vllm-coder directly: network policy lets only the team gateway reach it.
